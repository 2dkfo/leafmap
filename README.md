# 리프맵 LeafMap

부산을 찾은 외국인 채식 여행자가 먹지 않는 재료를 설정하면, 식당 메뉴의 재료와 양념 제품 성분표를 대조해 먹을 수 있는 메뉴를 보여주는 채식 지도 앱의 시제품입니다.

경성대학교 AI데이터기반서비스기획 중간과제 기획서를 바탕으로 만들었습니다.

> 이 시제품에 나오는 식당, 제품, 성분표는 모두 화면 검증을 위한 가상 데이터입니다. 실제 식당 정보가 아닙니다.

## 기획 배경

프랑스인 채식주의자 친구가 부산에 왔을 때 먹을 곳을 찾기 어려웠습니다. 검색으로는 채식 식당 정보가 부족했고, 막상 찾아간 식당에서는 양념이나 육수에 친구가 먹지 않는 재료가 들어 있었습니다. 그래서 식당 이름보다 실제 메뉴에 무엇이 들어가는지 확인할 수 있는 서비스를 기획했습니다.

**검증할 가설**
메뉴 재료와 양념 제품의 성분 근거를 함께 보여주면 방문 전에 메뉴를 고르는 시간과 시행착오가 줄어든다.

## 주요 기능

| 화면 | 할 수 있는 일 |
| --- | --- |
| 식단 설정 | 비건, 락토오보, 페스코, 직접 설정 중 하나를 고르고 제외 재료를 직접 바꿀 수 있습니다. |
| 지도와 목록 | 해운대, 서면, 부산 전체 중 지역을 고르면 조건에 맞는 메뉴 수와 확인이 필요한 메뉴 수를 식당별로 보여줍니다. |
| 메뉴 상세 | 기본 재료, 육수, 소스, 반찬을 나눠서 보여주고 메뉴의 판정 상태를 표시합니다. |
| 성분 근거 | 성분표 원문과 AI 해석, 확인일, 확인 주체를 보여주고 제품 분석과 식당 사용 확인을 따로 표시합니다. |
| 한국어 요청 | 식당 직원에게 보여줄 한국어 문장을 사용자의 제외 재료에 맞춰 만들어 줍니다. |
| 정정 제보 | 제보는 바로 정보에 반영하지 않고 검토 중 상태로 기록합니다. |

화면은 영어와 한국어로 바꿀 수 있고, 설정한 조건은 화면을 옮겨도 그대로 유지됩니다.

## 판정 기준

| 표시 | 기준 |
| --- | --- |
| 조건에 맞음 | 제외 재료를 대조할 근거가 있고 식당이 실제 사용을 확인한 경우 |
| 제외 재료 포함 | 식당이 사용을 확인한 재료 중 하나라도 제외 재료에 해당하는 경우 |
| 추가 확인 필요 | 제품을 모르거나 식당 확인을 기다리는 경우 |

성분표를 분석했더라도 식당이 그 제품을 실제로 쓰는지 확인하지 않았다면 추천을 확정하지 않습니다.

## 실행 방법

설치할 것이 없습니다. `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

지도는 인터넷에 연결되어 있어야 표시됩니다.

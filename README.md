# 리프맵 LeafMap 대시보드

부산을 찾은 외국인 채식 여행자가 먹지 않는 재료를 설정하면, 식당 메뉴의 재료와 양념 제품 성분표를 대조해 먹을 수 있는 메뉴를 보여주는 서비스의 대시보드 시제품입니다.

> 이 시제품에 나오는 식당, 제품, 성분표는 모두 화면 검증을 위한 가상 데이터입니다. 부산 방문 외국인 관광객 수치만 실제 공개 자료를 사용했습니다.

## 기획 배경

프랑스인 채식주의자 친구가 부산에 왔을 때 먹을 곳을 찾기 어려웠습니다. 검색으로는 채식 식당 정보가 부족했고, 막상 찾아간 식당에서는 양념이나 육수에 친구가 먹지 않는 재료가 들어 있었습니다. 그래서 식당 이름보다 실제 메뉴에 무엇이 들어가는지 확인할 수 있는 서비스를 기획했습니다.

**검증할 가설**
메뉴 재료와 양념 제품의 성분 근거를 함께 보여주면 방문 전에 메뉴를 고르는 시간과 시행착오가 줄어든다.

## 화면 구성

대시보드는 두 개의 탭으로 나뉩니다.

### 여행자 탐색

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 식단 유형 선택, 제외 재료 설정, 지역 선택 |
| 가운데 | 검색, 판정별 메뉴 수, 지도, 메뉴 목록 |
| 오른쪽 | 선택한 메뉴의 재료 구성, 판정 상태, 성분 근거, 한국어 요청, 정정 제보 |

지도에서 식당 핀을 누르면 그 식당 메뉴만 볼 수 있고, 판정별 버튼을 눌러 원하는 상태만 골라 볼 수 있습니다.

### 운영 현황

| 영역 | 내용 |
| --- | --- |
| 핵심 지표 | 등록 식당과 메뉴의 MVP 목표 대비 진행률, 분석 제품 수, 확인 대기 항목, 검토 대기 제보 |
| 데이터 처리 단계 | 식당 등록 → 제품 특정 → 근거 검토 → 식당 사용 확인 단계별 항목 수 |
| 판정 현황 | 식단 유형별로 식당마다 조건에 맞는 메뉴, 확인이 필요한 메뉴, 제외 재료가 든 메뉴 비율 |
| 관광객 추이 | 2023~2025년 부산 방문 외국인 관광객 수 |
| 확인 대기 목록 | 제품 불명이나 식당 확인 대기 항목과 다음 조치 |
| 성분표 분석 제품 | 제품별 동물 유래 성분, 확인일, 사용 메뉴 수 |
| 정정 제보 | 여행자가 보낸 제보를 검토하고 추가 확인으로 돌리거나 반려 |

여행자 탭에서 보낸 정정 제보가 운영 현황 탭에 바로 쌓입니다. 제보는 접수만으로 정보를 바꾸지 않고, 운영자가 추가 확인으로 돌리면 해당 메뉴가 "추가 확인 필요" 상태로 바뀝니다.

## 판정 기준

| 표시 | 기준 |
| --- | --- |
| 조건에 맞음 | 제외 재료를 대조할 근거가 있고 식당이 실제 사용을 확인한 경우 |
| 제외 재료 포함 | 식당이 사용을 확인한 재료 중 하나라도 제외 재료에 해당하는 경우 |
| 추가 확인 필요 | 제품을 모르거나, 식당 확인을 기다리거나, 정정 제보로 재확인 중인 경우 |

성분표를 분석했더라도 식당이 그 제품을 실제로 쓰는지 확인하지 않았다면 추천을 확정하지 않습니다.

## 실행 방법

설치할 것이 없습니다. `index.html` 파일을 브라우저로 열면 바로 실행됩니다. 지도는 인터넷에 연결되어 있어야 표시됩니다.
